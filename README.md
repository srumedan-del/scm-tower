# SCM Control Tower MVP

Starter web app untuk SCM Templates & Dashboards.

## Stack
- Next.js + TypeScript
- Supabase
- Tailwind CSS
- Recharts

## Setup
1. Copy `.env.example` menjadi `.env.local`
2. Jalankan `npm install`
3. Jalankan `npm run dev`

## Menu MVP
- Dashboard
- Shipment
- Vendor
- Receiving
- Outbound
- Inventory
- Warehouse Checklist
- Issue Log
- Settings
